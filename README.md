## 📜 Mystical Island Adventure Game

Welcome to **Mystical Island**, a Python text-based puzzle and exploration game. Solve riddles, crack codes, and make strategic choices to uncover hidden treasures and escape the island alive!

---

### 🔹 Gameplay Summary

- Text-based interactive exploration
- Six unique stages: logic, math, and critical thinking
- Treasure rewards and inventory management
- Game-over conditions based on user choices
- Account system with persistent high scores and saved items

---

### 🌟 Features

- ✅ User login & account creation  
- ✅ High score tracking and stage progress  
- ✅ Inventory system that persists across sessions  
- ✅ Randomized treasure rewards (10 total hidden artifacts)  
- ✅ Dynamic game stages with increasing difficulty  
- ✅ Treasure tracker at the end of each game

---

### 🛠️ Setup Instructions

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/mystical-island-game.git
   cd mystical-island-game
   ```

2. Run the Python script:

   ```bash
   python mystical_island.py
   ```

> ⚠️ Requires Python 3.x and runs in the terminal or command line.

### 📁 Files Included

- `mystical_island.py` — main game logic
